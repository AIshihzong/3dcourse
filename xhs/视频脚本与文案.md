# 小红书视频：七年级科学 3D 实验室

- 网站：https://g7-science.pages.dev
- 规格：竖屏 1080×1920，时长约 50 秒，字幕烧录进画面，无配乐（发布时在平台内选择音乐）。
- 素材：网站真实画面的录屏，用 Python（PIL）合成标题、字幕和转场，再用 ffmpeg 编码（脚本见本目录 capture.js、compose.py）。

## 设计思路

想让人愿意收藏、分享、评论，内容本身要“利他”：

- **收藏**：视频里每个场景都配一句能直接拿去考试用的口诀，相当于一份期末速记卡。
- **分享**：网站免费、打开就能用，平板上也能用，家长会愿意转发到班级群。
- **评论**：结尾抛一个问题，再给一个“评论区留言就送”的福利。

## 分镜（约 50 秒）

| 时间 | 画面 | 字幕 / 口播 |
|---|---|---|
| 0–3s | 大字标题，背景是凸透镜光线快速会聚 | **七年级科学 36 个考点，我做成了 3D 实验** |
| 3–6s | 首页：点“七上期末”，进度环转动 | 期中、期末考哪些，一键筛选 |
| 6–13s | 凸透镜成像：拖动蜡烛，像由小变大、由倒变正 | 口诀：**物近像远像变大**；u＜f 成虚像，这就是放大镜 |
| 13–20s | 光的折射叉鱼：看到的鱼在上方，鱼叉往下叉中 | 看到的鱼比真实的浅，**叉鱼要往下叉** |
| 20–27s | 声音：抽真空，铃声消失；三条跑道声速赛跑 | **真空不能传声**；v固 ＞ v液 ＞ v气 |
| 27–33s | 等高线地形：3D 山体压平成等高线图 | 等高线**越密越陡**；V 字尖朝高处是山谷 |
| 33–39s | 眼睛：近视眼成像在视网膜前方，戴上凹透镜后变清晰 | **近视戴凹透镜，远视戴凸透镜** |
| 39–44s | 星星点亮、徽章弹出、考前冲刺倒计时 | 做任务拿星星，还有 10 题限时冲刺 |
| 44–50s | 平板上横屏使用的画面，网址大字 | 免费，平板直接打开：g7-science.pages.dev。**收藏，期末前过一遍** |
